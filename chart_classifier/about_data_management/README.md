---

## chart_factory

Each script in `chart_factory/` generates synthetic images for a specific chart type using **matplotlib**. Generation randomises colours, fonts, data values, styles and layouts to maximise variety.

```bash
# Example: generate synthetic box charts
python chart_factory/box.py
```

Synthetic charts are used to balance classes that have few real-world examples (e.g. chord, quiver, venn).

---

## Public datasets

9+ public labelled chart datasets were aggregated, including FigureQA, PlotQA, ChartQA, Chart-to-Text, and others.

The combined total (real + synthetic) is approximately **67,000 images** distributed across 24 categories.

---

## Train / Val / Test split

The split is **70% / 15% / 15%** and is pre-computed in `pre_split_training_data_for_chart_classification/`. Each sub-folder contains images organised by category, compatible with `torchvision.datasets.ImageFolder`.

```
pre_split_training_data_for_chart_classification/
├── train/
│   ├── bar/
│   ├── box/
│   └── ...
├── val/
│   └── ...
└── test/
    └── ...
```
